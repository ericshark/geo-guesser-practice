# Agent Guidelines

## Agent skills

### Issue tracker

Issues and specs are tracked as local markdown files under `.scratch/rebuild/` (spec at `.scratch/rebuild/spec.md`, tickets at `.scratch/rebuild/issues/<NN>-<slug>.md`). See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context layout (`GLOSSARY.md` at the repo root and ADRs in `docs/adr/`). See `docs/agents/domain.md`.
