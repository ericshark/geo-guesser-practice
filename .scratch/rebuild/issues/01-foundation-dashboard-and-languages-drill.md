# 01: Foundation — Playable Country & Language Corpus Dataset + Local File Persistence + Dashboard & Languages Speed Drill

**What to build:** Establish the clean-room Apple-inspired app shell (light/dark system theme, crisp neutral surfaces, `1px` borders, and functional color accents), the canonical **Playable Country** dataset and **Language Group** corpus (**Sentences**, **Sign Text**, and **Tells** across all 10 Language Groups), the **ProgressStore** with automatic disk persistence to `data/progress.json` mirrored in `IndexedDB` (including JSON export, import, and reset), the **Dashboard** displaying per-Section **Mastery State** breakdowns (**Unseen**, **Learning**, **Recognized**, **Mastered**), and a working **Languages** Section with **Stage 0 Quick Prime** (**Contrast Card**) and **Stage 1 ARTS Interleaved Speed Drill** (plus **Tell Recognition** micro-questions) with highlighted **Tells**, translations, covered **Candidate Countries**, and keyboard shortcuts.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Canonical dataset defines all **Playable Countries** (including distinct GeoGuessr territories like Hong Kong, Macau, Puerto Rico, Faroe Islands, U.S. Virgin Islands, Bermuda, Réunion, Christmas Island) with verified **Coverage Tier** (`Official`, `Limited`, `None`), regional notes, **Driving Side**, signage languages, ccTLD domain, and currency.
- [ ] All 10 **Language Groups** (`East Asian`, `Southeast Asian`, `South Asian Scripts`, `Romance`, `Germanic`, `Central European Slavic & Hungarian`, `Cyrillic`, `Baltic & Finnic`, `Mediterranean / Middle East / Caucasus`, `African`) plus `All-Groups Mixed` have ≥3 confusable languages each, multiple authentic **Sentences** and **Sign Text** **Samples**, explicit **Tells** with character-span matchers, structural/gestalt fallback clues, and covered **Candidate Countries** (with uncovered countries noted only as footnotes).
- [ ] **ProgressStore** automatically persists and loads progress via a local Vite/Node middleware endpoint (`/api/progress` reading/writing `data/progress.json`), mirrors state to `IndexedDB`, and supports validated JSON backup export, import, and confirmation-guarded reset.
- [ ] **PracticeEngine** schedules skills using ARTS priority ($D = 2$ spacing delay, error weighting, response-time fluency weighting), never repeats the same **Sample** consecutively, and transitions skills accurately across **Unseen**, **Learning**, **Recognized**, and **Mastered** (4 of last 5 correct without assistance, last 3 consecutive under the fluency response-time ceiling).
- [ ] **Dashboard** renders each **Section** card with live **Mastery State** counts/rings, total trials, streak/session stats, and clean Apple-minimalist styling that follows system light/dark mode.
- [ ] **Languages** Section lets the learner pick a **Language Group**, review or skip the **Stage 0 Quick Prime** **Contrast Card**, and run **Stage 1 Interleaved Speed Drills** with a non-punishing fluency speed bar, full keyboard controls (`1`–`6`, `Enter`, `Escape`), and immediate (<100ms) color-coded feedback highlighting matched **Tells** inside the **Sample**, the English translation, and covered **Candidate Countries**.
- [ ] Unit/integration tests at the `PracticeEngine`, `ProgressStore`, and dataset integrity seams pass (`npm test`, `npm run typecheck`, `npm run build`).
