# 04: Coverage Section (Official vs Limited vs None Drills & Regional Map Quizzes)

**What to build:** Build the complete **Coverage** Section so the learner can rapidly master which countries have **Official**, **Limited**, or **None** Street View coverage through interactive regional map-clicking drills, rapid **Coverage Tier** classification drills, trap-country contrasts, and regional coverage breakdown notes for partially covered countries.

**Blocked by:** 03: Interactive World Map & Stage 3 Language → Candidate Countries Bridge

**Status:** resolved

- [x] **Coverage** Section lets the learner choose a regional focus (`World`, `Europe`, `Asia`, `Africa`, `Americas`, `Oceania`, or `Common Trap Countries` like China, Egypt, Morocco, Algeria, Belarus, Moldova, Venezuela, Bolivia, Cuba, Pakistan road gaps).
- [x] Interactive map drills ask the learner to click all covered (`Official` + `Limited`) or uncovered (`None`) countries within a region, or identify which country in a neighboring cluster lacks coverage.

- [x] **Coverage** skills report live **Mastery States** (`Unseen`, `Learning`, `Recognized`, `Mastered`) to the **Dashboard** and support **Guided Breakdown**.
