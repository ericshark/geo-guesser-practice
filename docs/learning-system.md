# Learning rationale and implementation status

Practice testing and distributed practice form the foundation, following [Dunlosky et al.](https://pubmed.ncbi.nlm.nih.gov/26173288/) and the [Rowland meta-analysis](https://pubmed.ncbi.nlm.nih.gov/25150680/). [Smith and Karpicke](https://pubmed.ncbi.nlm.nih.gov/24059563/) support format choices that preserve successful retrieval rather than always requiring short answers. [Pan and Rickard](https://pubmed.ncbi.nlm.nih.gov/29733621/) motivate unfamiliar examples and explicit country-level application; fact recall does not automatically transfer to scenes.

Immediate correction is a product choice for short sessions. Corrective explanations matter, but immediate feedback is not universally optimal. Study evidence does not validate these specific selection scores, mastery labels, or FSRS for visual country inference.

The app keeps retrieval history and scheduling separate. An introduction is exposure; a hinted correct answer is assisted practice. A multiple-choice answer supplies recognition evidence. A typed answer supplies recall evidence. The current aggregate accuracy combines formats and should be interpreted accordingly.

The current curriculum and selection implementation have limitations documented in the README. In particular, category balance, truly unfamiliar transfer variants, format-specific statistics, and conservative mature-retention gates remain outstanding. Do not infer scientific precision from the current labels.
